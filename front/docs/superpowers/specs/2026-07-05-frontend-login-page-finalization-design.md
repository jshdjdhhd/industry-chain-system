# Frontend Login Page Finalization Design

> 补录说明：本文按登录页多轮调整结果整理，用于归档最终登录页收敛工作。

## 背景

登录页是系统第一屏，需要兼顾科技感、企业级质感和真实功能边界。参考图只用于视觉方向，不能照搬其中未接功能，例如“记住我”“忘记密码”等入口。

## 目标

- 背景保持科技产业链视觉，不再频繁更换。
- 删除原左右分栏和右侧白色原卡片。
- 使用居中玻璃罩作为登录卡片背景。
- 卡片内只保留真实可用功能：系统标题、用户名、密码、登录按钮。
- 不添加任何未接后端的假功能。

## 非目标

- 不新增注册、找回密码、记住我等功能。
- 不修改登录 API、auth store 或路由守卫。
- 不改 dashboard、企业列表等非登录页范围。

## 视觉设计

登录页使用已有科技背景图作为全屏背景，中央放置半透明玻璃登录卡片。卡片上方展示系统名称和简短说明，表单使用 Element Plus 输入框和登录按钮，保持真实登录链路。

## 涉及范围

- `src/views/auth/LoginView.vue`
- `public/login-tech-bg.png`

## 验收标准

- `/login` 页面可访问。
- 背景图保持不变。
- 页面只有一个居中玻璃登录卡片。
- 不出现“记住我”“忘记密码”等未实现功能。
- 登录按钮继续调用原有 `handleLogin`。
