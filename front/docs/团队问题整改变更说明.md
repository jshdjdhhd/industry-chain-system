# 2. 后端整改说明

## 2.1 方法级权限控制

本次已在以下 Controller 上补齐 `@PreAuthorize`：

- `git.ggwzz.enterprise.controller.EnterpriseController`
- `git.ggwzz.tag.controller.TagController`
- `git.ggwzz.chain.controller.ChainController`
- `git.ggwzz.chain.controller.ChainNodeController`
- `git.ggwzz.matching.controller.MatchingController`

统一采用权限码格式：

```text
模块:资源:动作
```

本轮实际落地的权限码包括：

- `enterprise:enterprise:query/create/update/delete/inbound/outbound/batch-outbound/import`
- `enterprise:tag:bind/unbind/query/create/update/delete`
- `chain:chain:query/create/update/delete`
- `chain:node:query/create/update/move/sort/delete/link-enterprise/batch-link-enterprise/unlink-enterprise`
- `matching:task:query/create/execute/cancel/retry`
- `matching:result:accept/reject`
- `matching:manual-confirm:create`
- `matching:evaluation:run`

同时，鉴权测试不再保留“伪 403”方案。`SecurityFlowTest` 已改为真实覆盖：

- 无 Token 返回 `401`
- 无效 Token 返回 `401`
- 受限用户查询返回 `200`
- 受限用户访问写接口返回 `403`

## 2.4 matching 生命周期闭环

`matching` 模块本次已补全任务状态机：

```text
PROCESSING
RETRYING
COMPLETED
FAILED
CANCELLED
TIMEOUT
```

新增/补齐接口：

- `POST /api/matching/tasks/{taskId}/cancel`
- `POST /api/matching/tasks/{taskId}/retry`
- `POST /api/matching/evaluations/run?chainId=1`

本次实际落地能力：

- 处理中任务可协作式取消
- 失败、取消、超时任务可重试
- 重试创建新任务，并记录 `retry_from_task_id`、`retry_count`
- 超时状态单独落为 `TIMEOUT`
- 失败/超时原因写入 `error_message`

任务生命周期相关新增字段由 `V10__matching_task_lifecycle.sql` 落库：

- `retry_from_task_id`
- `retry_count`
- `cancelled_by`
- `cancelled_at`
- `error_message`

## 2.5 三 provider 统一评测

本次已将评测从“只评估当前注入 provider”扩展为统一输出三套策略结果：

- `RULE_BASED`
- `HYBRID_EMBEDDING_V2`
- `LLM_RERANK_V3`

评测输出已覆盖：

- `providerName`
- `sampleCount`
- `topK`
- `recallAtK`
- `top1Accuracy`
- `meanReciprocalRank`
- `fallbackCount`
- `misses`

## 2.6 `ChainNodeQueryService` 解耦

chain 模块不再返回 `RuleBasedMatchingProvider.ChainNodeInfo`，现已改为独立 DTO：

```java
public class ChainNodeCandidateDTO {
    private Long nodeId;
    private Long chainId;
    private String nodeName;
    private String nodePath;
    private String keywords;
    private Integer level;
}
```

接口调整为：

```java
List<ChainNodeCandidateDTO> listByChainId(Long chainId);
```

同步完成：

- `ChainNodeQueryService` / `ChainNodeQueryServiceImpl` 切换到 chain 自有 DTO
- matching 侧 provider 与 embedding 文本构造逻辑适配新 DTO
- 相关单元测试与集成测试同步更新

# 3. 前端整改说明

本次前端仅围绕 `matching` 页面与 API 配合后端闭环整改，涉及：

- `src/api/matching.ts`
- `src/api/mock.ts`

实际落地内容：
