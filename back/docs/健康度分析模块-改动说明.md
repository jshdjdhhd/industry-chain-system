# 健康度分析模块改动说明

## 一、模块概述

健康度分析模块是产业链管理系统的新增功能，用于对产业链节点进行健康度评估并生成分析报告。

### 核心功能
- **产业链 G6 可视化树图**：展示产业链结构和节点健康状态
- **健康度规则计算**：基于企业承载、单点依赖、同级均衡、企业质量四个维度计算健康分
- **异步报告生成**：调用大模型生成 Markdown 格式的健康分析报告
- **报告导出**：支持 HTML 预览、PDF 下载、Markdown 下载

### 设计原则
- **模块独立**：analysis 模块独立于 matching 模块，不写入智能挂链主流程
- **LLM 解耦**：使用 `llm.*` 通用配置，不依赖 `matching.llm.*`
- **实时 RAG**：从现有业务表检索数据，不新增独立知识库表
- **规则优先**：健康度由后端规则计算，大模型只解释不修改分数

## 五、健康度计算规则

### 1. 评分公式

```
节点健康分 = 企业承载得分 × 0.50
          + 单点依赖得分 × 0.25
          + 同级均衡得分 × 0.15
          + 企业质量得分 × 0.10
```

### 2. 指标计算

| 指标 | 计算方式 |
|------|----------|
| 企业承载得分 | 子树有效企业数：0→0, 1→25, 2-3→50, 4-7→75, ≥8→100 |
| 单点依赖得分 | 子树有效企业数：0→0, 1→20, 2→50, 3-4→75, ≥5→100 |
| 同级均衡得分 | 当前子树数 / 同父节点平均子树数：≥1→100, 0.7-1→80, 0.4-0.7→55, 0-0.4→25 |
| 企业质量得分 | 子树企业中有产值/税收/标签/主营/核心技术的比例综合 |

### 3. 健康等级

| 条件 | 等级 | 标签 |
|------|------|------|
| subtreeEnterpriseCount == 0 | EMPTY | 空白 |
| score >= 80 | HEALTHY | 健康 |
| score >= 60 | NORMAL | 一般 |
| score >= 30 | WEAK | 偏弱 |
| score >= 1 | RISK | 风险 |

### 4. 弱项原因

- EMPTY：该节点及子树暂无已挂载企业
- 企业承载得分低：子树企业承载偏低
- 单点依赖得分低：存在单点依赖风险
- 同级均衡得分低：明显低于同级平均企业承载
- 企业质量得分低：企业产值、税收或画像信息不足

## 六、报告生成流程

### 1. 创建报告

```
用户选择节点 → POST /api/analysis/reports
  → 参数校验
  → resolveScope 展开子树节点
  → 创建 analysis_report_task（status=PROCESSING）
  → 记录 @OperationLog
  → 调用 AnalysisReportWorker.execute(taskId)
```

### 2. 异步生成

```
AnalysisReportWorker.execute(taskId)
  → 查询任务
  → 构建诊断指标快照
  → AnalysisReportContextBuilder 组装结构化上下文
  → AnalysisReportPromptBuilder 生成提示词
  → LlmClient.complete 调用通用大模型
  → AnalysisReportResultParser 从 JSON 响应中提取 Markdown
  → ReportExportService 渲染 HTML
  → ReportExportService 导出 PDF
  → 写入 analysis_report_content
  → 更新 task 为 COMPLETED 或 FAILED
```

### 3. RAG 上下文结构

```json
{
  "chain": {
    "chainId": 1,
    "chainName": "产业链名称"
  },
  "scope": {
    "selectedNodeIds": [12, 15],
    "resolvedNodeIds": [12, 13, 14, 15],
    "scopeDescription": "上游：原材料与核心零部件等 4 个节点"
  },
  "metrics": {
    "summary": {
      "nodeCount": 4,
      "enterpriseCount": 18,
      "healthyCount": 1,
      "normalCount": 1,
      "weakCount": 1,
      "riskCount": 0,
      "emptyCount": 1
    },
    "nodes": [...]
  },
  "enterpriseSamples": [...],
  "matchingEvidence": [...]
}
```

### 4. 报告结构

```markdown
# {产业链名称}健康分析报告

## 一、分析范围
## 二、总体健康结论
## 三、关键风险节点
## 四、薄弱节点原因分析
## 五、已挂载企业支撑情况
## 六、管理建议
## 七、数据口径说明
```

## 十一、已知限制

1. **PDF 中文字体**：需要配置中文字体文件，否则中文会乱码
2. **LLM 响应格式**：依赖 LLM 返回 JSON 格式，Parser 有 fallback 处理
3. **上下文长度**：报告上下文有软上限裁剪（60000 字符），避免撑爆模型上下文窗口
4. **并发限制**：异步线程池 core=2, max=4, queue=50，高并发时可能排队
